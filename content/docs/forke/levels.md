Levels unlock privileges on Forke. They're separate from technical access, which comes from [skill tracks](/docs-demo/forke/skill-tracks).

## Five tiers

| Tier | Levels | Titles |
| --- | --- | --- |
| Early Game | 1–5 | Newcomer → Stack Explorer |
| Mid Game | 6–10 | Code Runner → Sprint Soldier |
| Skilled | 11–15 | Merge Specialist → Feature Shipper |
| Elite | 16–20 | Runtime Knight → Production Slayer |
| Legend | 21–25 | Silicon Phantom → Forke Legend |

## What each level unlocks

| Level | Unlock |
| --- | --- |
| 3 | Your own profile address, `forke.space/<username>` |
| 5 | Applying for team tasks |
| 7 | Intermediate payout tiers |
| 10 | XP streak multipliers |
| 12 | Priority task queue |
| 15 | Elite tasks, and reviewer eligibility with a trust score of 90%+ |
| 18 | Team lead eligibility |
| 20 | Mentor access |
| 25 | Private, invite-only projects |

## Achievements

Badges on your profile: First Blood, Bug Hunter, Clutch Commit, Untouchable, Monster Sprint, Streak God, Loot Goblin, Boss Mode and Forke Legend.

## Prestige

After level 25 you can prestige: your XP resets and you keep a permanent status, from **Ascended Developer** (an animated profile border) through Ghost in Production, Legendary Shipper and Kernel Lord to **Architect of Chaos** (the elite leaderboard and a custom badge).

See every level and its XP on the [Levels page](/levels).
