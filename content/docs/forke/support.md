## Contact

- **In the app:** open [Support](https://dashboard.forke.space/support) to start a ticket linked to your account.
- **Email:** [support@forke.space](mailto:support@forke.space). A person reads every message.
- **Contact form:** [forke.space/contact](/contact).

## Include this, and we can help faster

- The task ID or pull request link
- What you expected to happen, and what happened
- Screenshots or the exact error message

## Is something down?

Check [status.forke.space](https://status.forke.space) for live status and past incidents. You can subscribe there to get an email when something breaks and when it's fixed.

## Common questions

:::details I claimed a task but can't start in time
Let the reservation run out: that doesn't count against you. Abandoning a task after you've activated it does.
:::

:::details My payout hasn't arrived
Check the UPI ID in [Settings](https://dashboard.forke.space/settings) and the payout in [Earnings](https://dashboard.forke.space/earnings). If it shows as paid but nothing arrived, email support with the task ID.
:::

:::details My pull request was rejected automatically
The submission page shows the exact check that failed: a build error, a failing test, a file outside the scope, or a missing section in `FORKE_SUBMISSION.md`. Fix it and push again before the deadline.
:::

:::details I disagree with a founder's decision
Raise a dispute through support. See [Refunds & disputes](/docs-demo/forke/refunds-disputes).
:::
