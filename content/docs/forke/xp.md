XP measures your experience and consistency on Forke. It raises your [level](/docs-demo/forke/levels), one of the three gates that decide which tasks you can claim.

## How XP is earned

| Action | XP |
| --- | --- |
| Claim and activate a task | +5 |
| Task approved | Base XP for its budget (below) |
| Submit before half the deadline | +25 |
| 5-star rating | +30 |
| 4-star rating | +10 |
| Revision requested before approval | −20 |

## Base XP by budget

Bigger tasks award more, so your level grows with the work you take on.

| Budget | Base XP |
| --- | --- |
| ₹100–399 | 50 |
| ₹400–899 | 100 |
| ₹900–2,499 | 200 |
| ₹2,500+ | 350 |

## A worked example

You ship a ₹600 task:

| | XP |
| --- | --- |
| Activate the claim | 5 |
| Approved (₹400–899) | 100 |
| Submitted before half the deadline | 25 |
| 5-star rating | 30 |
| **Total** | **160** |

If the founder had asked for a revision first, you'd lose 20 of those.

## Streaks

A daily login streak adds 5 to 100 XP at milestones. From level 10 you unlock XP streak multipliers.

## Levels need

| Level | Total XP |
| --- | --- |
| 2 | 200 |
| 5 | 1,800 |
| 10 | 9,200 |
| 15 | 26,000 |
