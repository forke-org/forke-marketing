title: What is Forke?
description: A marketplace where developers earn by shipping small, scoped coding tasks as real pull requests, and founders get them done without hiring.
---

Forke is a marketplace for small pieces of real software work. A founder posts a scoped task with a fixed budget: fix this bug, build this form, convert this Figma screen. A developer who has proven they can do it claims the task, ships it as a pull request, and is paid by UPI the moment the founder approves.

There are no proposals, no bidding and no interviews. Your code is your application, and every approved task becomes verified proof of work on your public profile.

## How a task moves

Every task follows the same path, and Forke runs the parts in the middle for both sides.

| Step | Who | What happens |
| --- | --- | --- |
| **Post** | Founder | Writes a scoped task with a budget, a time estimate and the files it may touch, and funds escrow. |
| **Claim** | Developer | Claims a task they're eligible for and starts within 20 minutes. |
| **Build** | Developer | Works in a Forke-managed branch, never in the founder's repository. |
| **Submit** | Developer | Opens a pull request with a short structured write-up. |
| **Review** | Forke | Runs automated checks and an AI review, then writes a verdict card. |
| **Approve** | Founder | Reads the verdict card and approves or asks for changes. |
| **Paid** | Forke | Merges a clean pull request upstream and releases escrow to the developer's UPI. |

## What makes Forke different

**Everything is a pull request.** Work is never sent as a ZIP file, a link or pasted code. It lives in Git, so it can be reviewed, tested and merged like any other change.

**Forke sits in the middle.** Developers work in a mirror of the founder's repository. Nobody pushes to the founder's code directly, and nobody can merge their own work: only Forke merges, after approval.

**The money is there before the work starts.** Founders fund escrow when they post. Developers can see it's held, and it's released the moment the work is approved.

**AI helps, people decide.** An AI reviewer reads every submission and explains it in plain English, but the founder makes the call.

**Access is earned.** Each task is gated by three things you can't fake: your level, your skill tier in that area, and your trust score. See [How Forke works](/docs-demo/forke/how-it-works).
