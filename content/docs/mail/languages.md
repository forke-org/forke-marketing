There's no SDK to install. Every guide uses the language's standard HTTP client (or its most common one), so the code you copy is the code you run.

::languages

## The same request in every language

Every example on the [API reference](/docs-demo/mail/api) is shown in cURL, Node.js, Python, PHP, Ruby, Go, Rust, Java and .NET. Pick a language once and every example on the site switches to it.

## Moving from another provider?

If your code already uses Resend's request shape, there's a [Resend-style endpoint](/docs-demo/mail/api/emails/send-resend-style) that accepts it. See [Migrate to Forke Mail](/docs-demo/mail/migrate).
