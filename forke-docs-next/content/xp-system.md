You earn XP when a task is approved. XP raises your level.

## Ways to earn XP

- **Completed tasks.** Every approved task earns XP.
- **Speed bonuses.** Finishing quickly can earn extra.
- **Clean reviews.** Passing the pipeline cleanly earns extra.
- **Streak multipliers.** Shipping on consecutive days builds a streak.

## Tier multipliers

Your tier also changes how fast XP accumulates.

| Levels | Tier | XP multiplier |
| --- | --- | --- |
| 1–5 | Early Game | 1.0x |
| 6–10 | Mid Game | 1.2x |
| 11–15 | Skilled Tier | 1.5x |
| 16–20 | Elite Tier | 2.0x |
| 21–25 | Legend Tier | 2.5x |

See [Levels and unlocks](#levels-and-unlocks) for what each tier opens up.
