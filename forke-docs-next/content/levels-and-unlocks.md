## Tiers at a glance

| Levels | Tier | Focus | Bounty range |
| --- | --- | --- | --- |
| 1–5 | Early Game | HTML/CSS, basic bug fixes | ₹200 – ₹500 |
| 6–10 | Mid Game | React components, CSS logic | ₹500 – ₹1,200 |
| 11–15 | Skilled Tier | API hooks, full-stack features | ₹1,200 – ₹3,000 |
| 16–20 | Elite Tier | System architecture, database fixes | ₹3,000 – ₹8,000 |
| 21–25 | Legend Tier | Performance at scale, cloud DevOps | ₹8,000+ |

## Unlocks

### Early Game

- Basic bounties
- Public profile URL at level 3
- Team task applications at level 5

### Mid Game

- Intermediate payout tiers
- XP streak multipliers at level 10
- Warm standby queue access

### Skilled Tier

- Priority task queue at level 12
- Elite bounty eligibility at level 15
- Reviewer pathway entry

### Elite Tier

- Team lead eligibility at level 18
- Mentor access at level 20
- Advanced security clearance

### Legend Tier

- Private invite-only projects
- Prestige reset options
- Commit Warlord status badge
