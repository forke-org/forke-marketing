Founders use Forke to get small pieces of engineering work done without proposals, negotiation or invoices.

## Post a task

1. Describe the work and set the scope. See [Writing clear acceptance criteria](#acceptance-criteria).
2. Choose a bounty and tech stack.
3. Fund escrow. The bounty is locked before the task goes live. See [Escrow system](#escrow-system).

## While the task is open

A developer claims it and works in an isolated Forke branch. Nothing touches your main branch until you approve.

## Review a verdict

Every submission passes the [4-layer review pipeline](#review-pipeline) before you see it. You read a plain-English [verdict card](#verdict-card), not a raw diff, and then approve or request changes.

## Approve and pay

Approve once. Forke merges the PR and escrow releases to the developer automatically.

## Fees

Developers keep 100% of the listed bounty. Founders pay a 10% platform fee on top, so a ₹500 task costs ₹550.

> **Important** If something goes wrong, see [Refunds, timeouts and disputes](#refunds-and-disputes).
