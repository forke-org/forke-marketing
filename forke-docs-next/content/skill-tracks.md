Skill tracks match you with the kind of work you are best at.

## The four tracks

| Track | Typical work |
| --- | --- |
| Frontend | UI components, styling, accessibility fixes |
| Backend | APIs, data handling, server logic |
| Fullstack | Features that cross the frontend and backend |
| DevOps | Deployment, pipelines, cloud configuration |

## How tracks gate bounties

Specialised bounty categories require the matching track. Your track and your [level](#levels-and-unlocks) together decide which tasks appear in the [feed](#browsing-the-feed).

## Building a track

Complete approved tasks in a track to grow your standing in it. Your [profile](#profile) shows what you have shipped.
