This page walks the full developer journey. Each step links to a deeper guide.

## 1. Set up your account

- Connect GitHub: [Connecting GitHub and permissions](#github-connection)
- Add your UPI ID: [Account settings and UPI payouts](#account-settings)
- Review your public page: [Developer profile and proof of work](#profile)

## 2. Find and claim a task

Filter the feed by tech stack, level, reward and estimated time. Claiming gives you a 20-minute soft reservation. See [Browsing the bounty feed](#browsing-the-feed) and [Claiming a task](#claiming-a-task).

## 3. Build in your Forke branch

Forke creates a dedicated working branch for every claim. See [Forke branch workflow](#branch-workflow).

## 4. Submit and pass review

Link your PR and run pre-submission validation. The [4-layer review pipeline](#review-pipeline) then checks it. See [Submitting a pull request](#submitting-a-pr).

## 5. Get paid and level up

The owner approves a [verdict card](#verdict-card), the PR merges, and escrow releases to your UPI. You earn XP toward the next level. See [The XP system](#xp-system).

> **Note** Your completion rate and review record feed your [trust score](#trust-score). Claim what you can finish.
